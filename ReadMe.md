### Hi, I'm Jack Lu (I-Hao Lu)

PhD researcher working on **indoor localisation without infrastructure** — pedestrian dead
reckoning, Wi-Fi fingerprinting, magnetic-field cues and FTM ranging, plus the embedded
hardware that collects the data.

- 🔬 Research: PDR / inertial odometry, Wi-Fi & magnetometer localisation, indoor–outdoor
  detection, GNN-based positioning
- 🛠 Toolchain: PyTorch + PyTorch-Lightning, ROS, MongoDB data pipelines
- 🔌 Hardware: ESP32-S2/S3, STM32 (L4/L475), Raspberry Pi, Pmod NAV / MPU9250 / LSM9DS1
- 🧮 Also: HLS/FPGA implementations of sensor-fusion filters
